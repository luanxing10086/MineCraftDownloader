# Store listing (English)

## App name

MCD — Minecraft Downloader

## Short description

A downloader for licensed Minecraft players: vanilla, Fabric/Quilt/Forge/NeoForge, and Modrinth modpacks — pick once, download straight into your launcher folder.

## Long description

MCD only downloads. It prepares Minecraft, mod loaders and modpacks in one place.

**Features**

- Version list: releases / snapshots / all, with keyword search
- Loaders: Fabric, Quilt, Forge, NeoForge, with automatic stable or beta selection
- Fabric API: optional one-click install with version choice
- Modpacks: Modrinth `.mrpack` (slug, link or local file)
- Custom download: paste any http/https URL
- Version isolation: optionally write content to `versions/<version>/`, matching PCL and HMCL layout
- Mirrors: BMCLAPI (faster in mainland China) or Mojang official
- Output layout follows the official launcher spec and is recognised by PCL / HMCL / Prism

**Requirements**

- For licensed Minecraft users only
- Forge / NeoForge installation requires Java 17 or 21 on the machine
- The app does not launch the game and does not handle accounts
