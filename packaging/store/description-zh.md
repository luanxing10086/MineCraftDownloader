# 商店信息（中文）

## 应用名称

MCD — Minecraft 下载器

## 简短描述（≤ 200 字符）

面向正版用户的 Minecraft 下载工具：原版、Fabric/Quilt/Forge/NeoForge 加载器、Modrinth 整合包，一处选完直接下载到启动器目录。

## 详细描述

MCD 是一个只做下载的 Minecraft 工具，帮你把游戏本体、加载器与整合包一次性准备齐全。

**主要功能**

- 版本列表：正式版 / 快照 / 全部，支持关键字搜索
- 加载器：Fabric、Quilt、Forge、NeoForge，可按正式版或测试版自动选择
- Fabric API：选择 Fabric 时可一并安装，并可指定版本
- 整合包：支持 Modrinth 的 .mrpack（项目名、链接或本地文件）
- 自定义下载：粘贴任意 http/https 链接直接下载
- 版本隔离：可选把内容写入 versions/<版本>/，与 PCL、HMCL 的隔离结构一致
- 下载源：BMCLAPI 镜像（国内更快）或 Mojang 官方
- 目录布局符合官方启动器规范，可被 PCL / HMCL / Prism / 官方启动器直接识别

**使用前提**

- 仅面向已购买 Minecraft 的正版用户
- 安装 Forge / NeoForge 需要本机已安装 Java 17 或 21
- 本应用不启动游戏，也不提供账号登录

**声明**

本应用为非官方工具，与 Mojang Studios、Microsoft 无任何关联。应用不提供账号、不破解、不绕过正版验证，仅从 Mojang 及各加载器的公开官方接口下载文件。Minecraft 是 Mojang Studios 的商标。
